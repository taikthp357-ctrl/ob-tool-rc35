# SAP VBA Tool — hai file Excel dùng chung

Thư mục này tập hợp hai file người dùng gửi, giữ nguyên định dạng `.xlsm` và VBA. Các bản phát hành chính vẫn ở `../ob-tool/` và `../stock-fg-ma-body/`.

- `261010_OB_TOOL_V1_RC55.xlsm`: bản OB Tool RC55 do người dùng cung cấp (không phải bản RC mới nhất).
- `261008_Stock_FG_MA_BODY.xlsm`: bản Stock FG MA BODY do người dùng cung cấp.

Xác minh tính toàn vẹn bằng `SHA256SUMS.txt`. Đây là bản sao phục vụ lưu trữ chung; không xóa hay ghi đè tệp ở thư mục phát hành khác.
